# Contribuição

A versão final organiza o estudo de três fases. Correções de reprodutibilidade e investigações complementares com escopo definido são bem-vindas.

Descreva hipótese, protocolo, tolerâncias e critério de refutação. Preserve os dados de referência usando outro diretório ou uma cópia separada do repositório. Distinga observação, conjectura e demonstração. Registre sementes, regras de seleção, casos ausentes e limites da validação.

Rode python -m pytest -q e os quatro módulos do [guia de reutilização](REUSE_GUIDE.md). Documente alterações que afetem resultados, dependências ou formatos. Mantenha credenciais, caminhos pessoais e conversas fora do repositório.
