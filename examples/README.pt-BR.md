# Exemplos executáveis de reutilização

[Read in English](README.md)

Após instalar o pacote, execute os módulos a partir da raiz do repositório.

| Comando | Demonstração |
|---|---|
| python -m examples.scalar_optimization | Diferenciação automática escalar e descida de gradiente numa quadrática |
| python -m examples.tensor_derivatives | Validação de gradientes e curvaturas direcionais em lote |
| python -m examples.background_subtraction | Subtração de fundo por spline em um sinal espacial |
| python -m examples.stationary_landscape | Extremos de um potencial de dois poços e limites de bacias determinísticas |

Cada módulo compara a saída com um resultado analítico conhecido. Consulte o [guia de reutilização](../docs/pt-BR/REUSE_GUIDE.md).
